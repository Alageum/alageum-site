# Joint local site integration successor

This separate leaf binds the reviewed EDS/auth candidate and its test-performance
revision to 73 exact photography and investor-presentation paths. The three
catalog photo consumers have exact predecessor pairs; nine necessary proof
adapters and four test-support paths are likewise bounded. The proof coordinator,
all historical approval artifacts, package/lock files, catalog records, geometry,
RFQ and CMS contracts remain unchanged.

The new leaf imports only the existing proof-invocation utility and Node built-ins.
It never calls an inherited verifier or uses historical readers in production.
Inherited semantic and fixed-map checks remain in place; only final byte checks
and exact known predecessor routes delegate to this leaf. Unknown paths, wrong
predecessor hashes, incomplete or overbroad closure, mixed source, forged reports,
stale authority and changed current bytes fail closed. Default readers retain one
invocation owner and complete final rereads. Explicit readers remain uncached.

Historical controls use a pinned test-only snapshot of the sixteen changed prior
paths. New joint tests use actual current source bytes, one same-reader explicit
success/refusal matrix and all current default-reader routes. Mutation checks cover
every current dependency and persistent or same-invocation tampering. Synthetic
authority exists only in a Map or disposable directory, never in this checkout.

Photography is illustrative and source-attributed. Fifteen assets cover six
manufacturers, three projects and bounded equipment contexts. Ninety-four of 843
catalog rows match explicit reviewed identities; unmatched/changed rows retain
honest existing technical/CMS visuals. Publication rights require owner clearance.
Corporate layouts are opt-in; the approved shared palette does not rewrite the
pinned global/catalog styles or engineering route layout.

EDS remains off by default, with no trusted runtime verifier or real delivery.
Google needs issued client configuration and a live end-to-end check. eGov remains
unavailable pending official eligibility, specification and access. No release,
security waiver, publication, provider agreement or production approval is implied.

A fresh independent reviewer must approve the exact new dependency map. Then the
full unified unit suite, production build and joint browser/responsive checks must
run on the final candidate. Previous reports keep their original scope; pending or
interrupted tests are never rewritten as accepted final results.

The baseline contains 697 exact prior pins: the full 680-path immediate proof
closure/authority and 17 unchanged local corporate, photo-consumer and Design
dependencies. Their bytes are frozen from the prior commit. Existing catalog-source
page-image boundaries are inherited unchanged; no new claim expands that scope.
