## Устранённые повторы

- Показатели CompanyMetrics оставлены на главной. Со страницы компании и страницы инвесторов одинаковый блок удалён. Инвесторам дан отдельный контекст сравнения периодов.
- Подробная хронология сосредоточена в разделе истории. Со страницы компании удалён её повтор.
- Интерактивная география принадлежит странице предприятий. Второй атлас со страницы компании удалён.
- Скопированные с главной этапы ProjectStages удалены со страницы компании. Производство раскрывается через реальные технологические операции.
- Универсальные завершающие CTA удалены из страниц документов, предприятий, проектов и решений. Вместо них оставлены действия по текущей задаче. Общий подвал сохранён.
- Крупные условные иллюстрации удалены из детальных кейсов без проверенной фотографии объекта. В списке кейсов условные миниатюры остаются явно подписанными.
- Исторические награды привязаны к КТЗ или конкретному руководителю, а не автоматически ко всей группе.
- В контактах нет перехода «Подготовить запрос»; доступны телефон, почта и поиск отделов.

## Финальный браузерный проход

Сохранены 1 368 снимков для 456 адресов и режимов: desktop 1600×1000, tablet 820×1180, mobile 390×844. В итоговом журнале нет переполнений, отсутствующих снимков, ошибок страниц и битых загруженных изображений. Все 339 русских страниц (основные, детальные и 284 архивных) проверены в трёх размерах. 55 основных и детальных страниц дополнительно проверены на английском и казахском; локализованный архивный читатель — на одном исходном материале в каждой версии. Главная проверена отдельно.

Исправлена обнаруженная в production-сборке ошибка DYNAMIC_SERVER_USAGE у локализованных профилей партнёров: языковые оболочки больше не экспортируют неполные параметры статической генерации; метаданные локализуются тем же способом, что у проектов. Аналогичная оболочка архивного читателя исправлена и проверена.

Записи с префиксом QA — изолированный предпросмотр существующих фикстур: одна CMS-страница и три статьи. Они проверяют оформление шаблонов, не означают публикацию в CMS. Основной localhost:3000 использует API новостей; в редакционном разделе сейчас нет опубликованных записей. Динамические будущие публикации невозможно проверить заранее.

Снимки в указателе преимущественно показывают первый экран. Длинные исходные архивные тексты просмотрены визуально выборочно; наличие всех 93 локальных архивных иллюстраций проверено отдельно. Проверка DOM не заменяет сплошную ручную оценку каждого пикселя длинных материалов.

Основной frontend и backend оставлены работающими, временный сервер production-проверки остановлен. Push, merge, деплой, публикация CMS и изменения инфраструктуры не выполнялись.
