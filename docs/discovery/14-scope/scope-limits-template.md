# Scope limits template

Значения должны попасть в Final ТЗ. Неопределенное значение нельзя трактовать как unlimited или included.

| Dimension | Included quantity/limit | Unit/definition | Source | Acceptance method | Excess handling | Status |
|---|---:|---|---|---|---|---|
| Public page types | [NEEDS_CLIENT] | Types/templates | Design/content inventory | Approved list | CR assessment | OPEN |
| B2B screens/journeys | [NEEDS_CLIENT] | Unique screens/flows | Journey map | Approved map | CR assessment | OPEN |
| Roles | [NEEDS_CLIENT] | Business roles | RBAC matrix | Signed matrix | CR assessment | OPEN |
| Integrations | [NEEDS_CLIENT] | Providers/passports | Integration overview | Accepted passports | CR assessment | OPEN |
| Product categories | [NEEDS_CLIENT] | Taxonomy nodes/levels | Catalog inventory | Import/search test | CR assessment | OPEN |
| Product attributes | [NEEDS_CLIENT] | Definitions/values | Product template | Sample validation | CR assessment | OPEN |
| Document types | [NEEDS_CLIENT] | Types/workflows | Document matrix | Access/version tests | CR assessment | OPEN |
| Notification templates | [NEEDS_CLIENT] | Event × channel × locale | Notification inventory | Delivery test | CR assessment | OPEN |
| AI use cases/tools | [NEEDS_CLIENT] | Approved matrix rows | AI matrices | Golden/security tests | CR assessment | OPEN |
| Migration records/files/history | [NEEDS_CLIENT] | Count/GB/years | Migration inventory | Reconciliation | CR assessment | OPEN |
| Locales | [NEEDS_CLIENT] | RU/KZ/EN/CN/UZ or other | Content decision | Locale UAT | CR assessment | OPEN |
| External services | [NEEDS_CLIENT] | Named services | Passports | Connectivity/UAT | CR assessment | OPEN |
| Organizations/users | [NEEDS_CLIENT] | Active/peak | NFR | Load/UAT | Capacity review | OPEN |
| Maximum upload/request/AI input | [NEEDS_CLIENT] | MB/chars | NFR/security | Boundary tests | Config/CR review | OPEN |

Также фиксируются explicitly excluded features, environments, content creation, data cleansing, licenses, vendor fees, training, support period and client-provided work.
