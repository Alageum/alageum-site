# Главная, компания, география и контакты

## Объём

- Главная: реальное производство, направления каталога с общей библиотекой SVG,
  этапы работы группы, города, источниковые проектные карточки, переход к менеджеру.
- Компания: история, миссия, производственные компетенции и ссылки на источники.
- Предприятия: обзорная карта пяти городов, шесть прежних профилей, проверенные
  адреса/каналы, URL-фильтр города и история навигации.
- Контакты: единый отдел продаж, поиск 11 региональных контактов, понятное
  поведение почтовых ссылок, подготовка обращения, раскрываемые ответы.

Красный, белый и тёмно-синий используются с существующими токенами, шапкой и
футером Design/. Изменения не затрагивают 238 продуктов, их идентификаторы,
иконки, админку, серверные маршруты, Vercel, права доступа и отправку запросов.

## Локальная проверка

- Пройдено: `npm run check` — lint, все 116 unit-тестов, штатная production-сборка.
- Пройдено: `npm run build:preview` — отдельная статическая публичная сборка.
- Пройдено: `node --test tests/company-pages.test.mjs` — шесть новых проверок источников,
  контактов, географии, фильтрации, истории и честного поведения формы.
- `npm run test:e2e:company`: 20 сценариев (10 desktop + 10 mobile).
- `npm run audit:company`: 16 снимков (4 страницы × 1440 / 768 / 390 / 320 px),
  проверка переполнения, изображений и ошибок выполнения.

Локальные Chromium E2E/скриншоты в текущем исполнителе **не были выполнены**:
Chromium завершается до открытия страницы с `socket() failed: Operation not
permitted`. Повторный разрешённый запуск не изменил ситуацию. Облачный браузер
не получил доступ к локальному превью (`ERR_BLOCKED_BY_CLIENT`). Это блокировка
среды, а не результат проверки страниц. Не объявлять визуальную проверку
пройденной только на основании локального запуска.

Первый CI-прогон на дереве `619d9b0f07a03bada11ec01fa96424209577e34a`
прошёл: все 20 Chromium-сценариев, 16 размеров страниц без переполнений,
ошибок выполнения и битых основных изображений. По реальным PNG дополнительно
улучшены переносы русских слов на 320/390 px и прогрузка ленивого логотипа
в полноразмерных снимках. Для окончательной оценки используйте артефакты
последнего коммита PR, а не снимки первого прогона.

Workflow `Company pages browser QA` запускает production-сборку, реальные
Chromium desktop/mobile сценарии и viewport-аудит в GitHub Actions. Артефакт
`company-pages-visual-qa-<commit>` хранит PNG, JSON-результат, trace ошибки и лог
локального сервера CI. Workflow не имеет секретов, прав публикации или деплоя.
Все проверки запускаются на одноразовой локальной копии приложения.

   согласия и политику хранения. Сейчас запрос подготавливается локально,
