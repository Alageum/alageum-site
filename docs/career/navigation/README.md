## Итоговая карта

| Пункт | URL | Назначение |
|---|---|---|
| Карьера | `/careers` | Профессии, рабочая среда, обучение на конкретном предприятии, переход к поиску |
| Вакансии | `/careers/vacancies` | Поиск и фильтры существующих публикаций с честным статусом |
| Стажировки | `/careers/internships` | Программа для студентов, направления, подготовка, отдельный контекст дуального образования |

| Публикация вакансии | `/careers/vacancies/production-director`, `/careers/vacancies/construction-director` | Существующие задачи, требования и неподтверждённая актуальность |

На мобильном те же четыре основных пункта. В футере четыре основных направления и две ссылки на основной сайт; внутри одного меню нет повторяющихся адресов. Второй шапки нет. Активный пункт определяется по наиболее конкретному маршруту; детали вакансии относятся к «Вакансиям», форма стажировки — к «Отклику». EN/KK сохраняют префикс языка.

## Что было исправлено

В браузере до правки обнаружены 15 ссылок верхней навигации (4 основных + 11 выпадающих) и 12 ссылок футера. Названия «Компания как работодатель», «Люди и команда», «Предприятия», «Кандидатам», «Как проходит найм», «Этапы и вопросы», «Мои черновики» выдавали части существующих страниц за самостоятельные разделы. «Все направления» повторяло каталог вакансий. Теперь в верхнем меню четыре ссылки, в футере шесть.

Новые пустые страницы не создавались: расширены четыре существующие страницы с разными задачами. Программа стажировок и заполнение обращения разделены по смыслу. Развитие сотрудников представлено подтверждённым материалом УТЗ на странице работодателя, а не ошибочным переходом к стажировкам.

Совместимые старые URL остаются только перенаправлениями: about → careers; team/workplaces → careers#workplaces; learning → careers#learning; process → careers/apply#preparation. В меню их больше нет. Для серверных 308 подготовлен `../redirects.json`.

Эталон — главная основного сайта, снятая отдельно в reference screenshots. Сохранены её шрифты, корпоративный hero, кнопки, сетка и поля контейнера. Локальные композиции не меняют глобальные стили. На 1440px первый экран использует поля 56px; на 390px — 24px. Реальные фотографии АЭМЗ и Asia Trafo используются с подписями; люди не выдаются за стажёров. В форме устранена возможность ввода до гидратации, при которой ранний ввод мог теряться.

## Ограничения

Живая CMS/БД и сервер приёма HR недоступны: две существующие вакансии имеют неподтверждённый статус, подтверждённо открытая выдача пуста. Форма честно сохраняет локальный черновик и готовит письмо, не сообщает об отправке. В production потоковая страница отсутствующей вакансии может вернуть HTTP 200 с not-found интерфейсом; безусловный HTTP 404 и серверные 308 требуют согласованной интеграции общего роутера. Физические Safari/телефоны и скринридер не проверялись.

Изменения общей шапки/футера находятся только в данном worktree. Для объединения с параллельной работой подготовлены `integration.md` и `shared-integration.patch`; основной checkout не перезаписывался.
