# Безопасная очистка «Карьеры» — 01.11.2026

Область проверки: локальные careers-компоненты, маршруты и переводы, CareerApplication/VacancyDirectory, ссылки на используемые общие компоненты. Не заявляется очистка всего проекта. Изменения этой итерации ограничены тремя исходными файлами.

## Удалено и объединено

- `frontend/components/careers/translations.json`: удалены 47 ключей EN/KK от заменённых вариантов hero, старых блоков развития, прежнего текста стажировок, старых подписей фотографий и CTA. Оставлено 123 используемых ключа. Список удалённых — `removed-translations.json`. Перед удалением проверены ссылки во всех JS-файлах app/components/lib, включая данные, форму и динамические подписи.
- `frontend/components/careers/careers.css`: объединены идентичные desktop/mobile правила h2 для career-environment, career-students и career-plant-learning. Удалены две повторные декларации, значения и точки перелома сохранены. Неиспользуемых career-классов по исходникам не обнаружено, активные стили не удалялись.
- `frontend/components/ecosystem/CareerApplication.js`: два импорта из careers/Text объединены в один. Поведение формы не изменено.

Новых возможностей, зависимостей или страниц нет. Package manifests и lock-файлы не менялись. Целиком удалённых исходных файлов нет: оставшиеся локальные модули используются текущими страницами. Никаких reset, push, merge и деплоя.

## Что сохранено намеренно

- Общие `ecosystem/Parts`, LocaleElement/LocaleImage, CorporatePage и корпоративные стили используют другие разделы, включая новости и проекты. Их очистка выходит за область задачи.
- Повтор локальной readiness-проверки в форме и каталоге оставлен: работает и обеспечивает гидратацию; создание общего hook ради трёх констант не требуется для удаления устаревшей реализации.
- Старые маршруты careers/about, team, workplaces, learning, process остаются поддерживаемыми перенаправлениями для внешних ссылок, а не забытыми страницами.
- Официальные архивные материалы, фотографии и manifest сохранены: ими пользуются другие страницы; неподтверждённые вакансии нужны для честного отображения существующего источника.
- Общие зависимости не удалялись: специфических новых careers-пакетов не добавлялось, отсутствие использования во всём проекте не доказывалось.
- Исторические отчёты/скриншоты оставлены как доказательства предыдущих итераций. Они не импортируются приложением. Полный diff содержит их, исходный diff — нет.
