# Повторная правка «Карьеры»

Эталон: главная основного публичного сайта `/` на `localhost:3000`, дополнительно её неизменённая копия `/` на `localhost:3101`. Просмотрены на одинаковых viewport 1440×960 и 390×960. В основном проекте отличается текст CTA главной; общие `brand-experience.css` и `globals.css` совпадают побайтово. Чужие файлы читались только для сравнения.

## Что было обнаружено в браузере

- Заголовки «Карьеры» одинаково крупные на всех страницах: 95,04 px на desktop и 48 px на телефоне, включая каталог и форму. Главная публичного сайта: 90,72 и 40,95 px. Семейство шрифта при этом уже совпадало: Helvetica / Arial; проблема была в шкале и композиции.
- Собственный фон #f7f7f5, жёлтые уведомления, отдельные кнопки и символы-стрелки, анимация появления и растянутые вступления.
- Фото после заголовка превращало первый экран в длинное вступление; иллюстрация оборудования на странице стажировок не объясняла программу.
- Числа напряжения и отдельная секция про «Кайдзен» отвлекали от выбора работы. Предупреждения об уточнении у HR повторялись.
- Переопределение `.eco-container` и собственный расчёт боковых полей усложняли общую сетку.

Исходное состояние сохранено в `before-*.png`. Текущий Git diff состоит из моей предыдущей работы в ветке `career`; общие файлы и изменения «Компании» не включены. Ранее существовавшие форма, IndexedDB/localStorage, источник двух публикаций и общая навигация сохранены.

## Исправление

- `CareerShell` использует существующий `CorporatePage`; основная страница — существующие корпоративные `corp-home`, hero, `SectionHeading`, `corp-stages`, `site-container`, кнопки и `CorporateArrow`. Общие компоненты и CSS не редактировались.
- Первый экран: официальная фотография работников АЭМЗ в том же оформлении, что hero публичной главной. Кнопка вакансий видна сразу. Нет второго меню.
- Основная страница сокращена до направлений, конкретной рабочей среды и перехода к программе студентов. Удалены напряжения, отдельная секция «Кайдзен», лишние повторения и собственная анимация.
- Каталог: компактный заголовок, поиск без лишней панели, фильтры, реальные сохранённые публикации с явным неподтверждённым статусом и самостоятельное пустое состояние.
- Карточка: возврат к списку, название, статус, задачи и требования, условия и действие. Длинная строительная позиция также проверена.
- Стажировки: убрана случайная иллюстрация оборудования; оставлены аудитория, направления и подготовка обращения.
- Форма: компактная шапка, рабочая сетка полей, инструкции и FAQ. Отправки на сервер не имитирует.

Hero главной и «Карьеры» фактически используют одинаковые шрифт, размер и отступы: desktop 90,72 px и 56 px слева; mobile 40,95 px и 24 px слева. Общие контейнеры содержимого: 56 / 40 / 20 px с ограничением 1392 px. Внутренние страницы имеют меньшие заголовки: 57,6 px при 1440 и 34 px на телефоне. Различается назначение и композиция страниц, а не визуальная система.

## Проверка

- Просмотрены все существующие основные страницы: `/careers`, `/careers/vacancies`, обе `/careers/vacancies/:id`, `/careers/internships`, `/careers/apply` — desktop и mobile. Фотографии проверены после загрузки и прокрутки, с осмысленными alt. Переполнения и ошибок JavaScript нет.
- Шесть браузерных сценариев прошли: путь кандидата, фильтры/пустые результаты, файл и лимит, сохранение/скачивание/удаление, ошибки хранилища, подготовка письма с честным статусом, EN/KK, старые ссылки, reduced motion и неизвестный ID в dev. Пять завершились в общем запуске; последний mobile storage-failure успешно запущен отдельно после остановки процесса общего прогона. После последней текстовой правки каталог и мобильный путь перепроверены.
- 21/21 существующих тестов (`ecosystem-domain`, `public-content`, `photography`) прошли.
- ESLint изменённых файлов прошёл.
- Production build `.next-profile` прошёл, включая 1229 статических страниц проекта. После этого убрано только повторное текстовое уведомление каталога; последующая проверка — ESLint и браузерный путь.
- `git diff --check` без ошибок.

Финальные снимки: `desktop-home.png`, `mobile-home.png`, `desktop-vacancies.png`, `mobile-vacancies.png`, `desktop-vacancy.png`, `mobile-vacancy.png`. Список снят на вкладке «Все публикации»: это сохранённые материалы, а не подтверждённые открытые вакансии. Пустой актуальный список — отдельные `*-vacancies-empty.png`. Остальные страницы — `*-internships.png`, `*-apply.png`, длинная позиция — `*-construction.png`. `preview-*` — первые экраны; `public-reference-*` — эталон основного сайта. Скриншоты не скрывают элементы интерфейса; в dev скрыт только служебный портал Next.js.

## Ограничения

Физический телефон, Safari и screen reader не проверялись. Живая CMS/HR-интеграция и фактический приём работодателем не доступны; форма остаётся локальным черновиком и подготовкой письма. Тестовые заявки HR не отправлялись. Источник не подтверждает открытый набор; данные не подменялись. Требования к подтверждению прав на существующие официальные фотографии и ограничение HTTP 200 для неизвестного ID при production streaming остаются из основного отчёта. Общий proxy, меню, футер и глобальные стили не изменялись. Push, merge и деплой не выполнялись.

Дополнительно: все пять основных экранов проверены при ширине 320 px без переполнения; первая клавиатурная точка — «Перейти к содержанию». Список переснят с prefers-reduced-motion, чтобы исключить незавершённый smooth scroll при захвате. Это не меняет его внешний вид.
