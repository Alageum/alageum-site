# ALAGEUM icon audit B: pages 60–98

## Result

- 33 reviewed families / 144 unchanged records; 28 available family crops inspected directly
- 18 reusable 64×64 SVG symbols added; existing verified forms reused where appropriate
- 25 explicit record overrides preserve mixed-family and scheme-only exceptions
- Icon provenance in this range: 115 source-based family silhouettes; 29 explicitly typical/unconfirmed records
- Five families lack exterior drawings in this range. ГРЩ, the sixth catalogue family without a drawing, is handled by audit A
- No source images, product records, electrical data, 3D type map or 3D geometry changed

## Inspection

Read every available crop in frontend/public/catalog-products for the 33 families below. Full pages 60, 61, 67, 72, 73 confirm the missing drawings. Full pages 69, 81, 84, 86, 93 and 94 resolve the mixed forms and variant associations. Pages 81 and 84 were rotated for correct reading of the exterior elevations. Original assets were not changed.

## Explicit exceptions

- ПР / ШР11 / ПР-11: the common open-panel drawing is retained only as a typical symbol for each unlabelled variant
- ПТМ/ТДЕ: family symbol shows both enclosure constructions. v012 matches the caption ПТМ(Д)-У1; v013 matches ТДЕ(Д)-9-У3. Eleven rated or ambiguous records are explicitly typical with separate enclosure forms
- БДРМ v010/v011: designation exists only in circuit diagrams; typical drainage-block icon, no claim of a mechanically verified enclosure
- УКЗВ v001/v003/v005: source-based overhead-input silhouette. v002/v004/v006/v007: typical cable-input cabinet without overhead bushings, because no cable-input exterior drawing is confirmed
- АТП-2×25: actual source page 81 is a closed modular building with two front doors and side bushings, not an exposed transformer frame
- ПСК-27,5-5: source page 84 explicitly names the sole model variant and depicts the building with external elevated contact bank; multiple views are not different variants
