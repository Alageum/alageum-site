ПОДБОРКА ФОТОГРАФИЙ ALAGEUM · 12.10.2026

Это отдельные данные для будущего объединения с сайтом. Сайт, база и код не менялись; тесты приложения не запускались.

РЕЗУЛЬТАТ ПЕРВОГО СИСТЕМАТИЧЕСКОГО ПРОХОДА
Проверен список всех 843 записей / 175 групп. Сохранено 66 уникальных визуально проверенных изображений-кандидатов: 65 фотографий и 1 фотоколлаж.
У 173 записей есть хотя бы один подходящий кандидат серии/типа; у 47 — два и более. Для 142 записей доступны только отдельно отмеченные общие фото типа. Для 528 записей подходящие фото пока не подтверждены.
Это НЕ 843 комплекта по 2–3 точных фотографии каждого исполнения. Пробелы оставлены явно, вместо чужих или неверно подписанных трансформаторов.

КАК СМОТРЕТЬ
1. contact-sheets/ — обзор всех отобранных изображений с ID.
2. selected-images/ — исходные файлы кандидатов; водяные знаки не удалялись.
3. photo-candidates.csv/json — подписи, источник страницы, оригинальный URL, права и ограничения каждого кадра.
4. photo-record-coverage.csv/json — строго 843 строки со стабильным productId, рекомендуемыми фото, отдельными фото общего типа и пробелами.
5. photo-family-coverage.json — все 175 групп и результаты поиска.
6. photo-unverified-leads.json — ссылки, которые не удалось визуально проверить; они не посчитаны как найденные фотографии.
7. photo-rejected.json — конфликтные подписи, чертежи, повторы и контекстные фото, не подходящие для автоматической привязки.

ОГРАНИЧЕНИЯ
- Фото серии не подтверждает мощность, обмотки, напряжение, класс потерь или климатическое исполнение каждой записи. Подтверждённых точных совпадений всех параметров SKU: 0.
- Фото с одинаковым сюжетом, уменьшенные копии и обрезки не считаются разными ракурсами.
- Фотографии ТМ с расширителем не подменяют ТМГ. Корпусное и открытое исполнение сухих трансформаторов разделены.
- Внешние источники иногда подписывают изображения неверно. Например, карточка ТМГ-100 показывает шильдик ТМГ-160/10. Такой кадр оставлен только как фото серии.
- 13 файлов имеют меньшую сторону менее 300 px: полезны как варианты для выбора, но могут быть недостаточны для крупного показа.
- Права на публикацию не подтверждены ни для одного файла. Это исследовательская подборка; перед размещением на сайте требуется разрешение правообладателя. Публичный URL сам по себе не является лицензией.
- Первый проход не доказывает отсутствие других фотографий в мире. Для пустых и спорных позиций нужны дополнительные подтверждённые исходники/заводская съёмка.
