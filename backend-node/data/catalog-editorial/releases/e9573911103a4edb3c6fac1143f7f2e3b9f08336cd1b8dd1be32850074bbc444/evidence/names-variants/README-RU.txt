Проверены все 843 исходные записи. В первоначальных названиях были 43 группы совпадений (98 записей), после сокращения — 62 группы (174 записи); ещё одна запись совпадала после нормализации тире. Исправлено 175 подписей, все 843 теперь различаются. Сами маркировки не менялись.

Начните с names-and-variants-review.csv: исходное название → прежняя короткая подпись → новая подпись. catalog-variant-identity.json содержит отдельные marking, variant_summary, recordRole, group_keys и canonicalAttributes. Исходное имя, stable productId, источник и каждое использованное отличие сохранены. sourceRecordSha256 связывает запись с неизменным исходником.

Правила импорта
1. Объединять только по productId, не по имени, маркировке или фотографии.
2. displayLabel предназначен для краткой различимой подписи. marking — буквальная существующая маркировка; если показывать только её, требуется видимый контекст варианта.
3. catalog-hierarchy.json разделяет семейства, навигационные группы моделей и существующие записи исполнений. 142 семейства и семь справочных групп не смешиваются. 686 модельных групп — ключи навигации, не заказные артикулы.
4. Дочерние записи определены по их familyId. В источнике 20 таких ссылок отсутствовали в обратном списке variantIds; восстановлены только новые навигационные связи, исходные массивы не переписаны.
5. configurationOptions сохраняются вложенными. Всего 501 исходный объект в 1 351 месте: 389 с исходными ID, 112 без. Для объектов без ID configurationKey — технический ключ ссылки на исходные данные, не выдуманная маркировка и не товар. 19 повторяющихся вложенных подписей различены по напряжению и мощности.
6. Explicit modelId связывает опцию только с указанной моделью. Полный массив семейства, повторённый у 36 исполнений, и шаблоны code-option не означают, что каждый вариант обладает всеми перечисленными характеристиками.
7. canonical-attributes.csv, canonical-attribute-evidence.json и attribute-filter-values.json дают характеристики и точные основания. Альтернативы, диапазоны и сочетания остаются исходным текстом: их нельзя автоматически перемножать в новые товары.
8. Схемы обмоток, ВН/СН/НН, охлаждение, материал, класс потерь и способ регулирования различаются только там, где источник это сообщает. Испытательные, изоляционные и напряжения короткого замыкания выделены отдельно от рабочих напряжений.

Нет доказанных полных дублей для удаления. Общие технические таблицы у разных кодов или у семейства и его моделей не доказывают дубликат. Неуказанный материал обмоток остаётся неизвестным. Неполная маркировка ТДЕД-?-3,0, спорные единицы, номиналы/ступени и расхождения написания сохранены с предупреждениями.
