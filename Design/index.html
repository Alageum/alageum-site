Composition rules
01 / RHYTHM

Give each chapter a surface

76 px section spacing on desktop, 48 px on mobile. Alternate neutral chapters and white content; reserve graphite for a map or closing action.

02 / TYPOGRAPHY

Specific, readable copy

One clear H1. Body copy 15–16 px, line height around 1.75. Headings explain capabilities, enterprise profiles and the scope of each project without unsupported performance claims.

03 / EVIDENCE

Actual images and context

Use the source image’s true subject and a precise caption. Distinguish a factory, supplied equipment and a completed project. Keep source links and project status.

Shared palette: all routes. Corporate composition: home, company, enterprises, projects, solutions, contacts, documents and editorial pages. Technical catalog, comparison, RFQ and workspace: color alignment only. Logos and photographs are not recolored.
