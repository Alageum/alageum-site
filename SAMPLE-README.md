Образец для обсуждения интерфейса, подготовлен 30 сентября 2026.
Основа: существующий репозиторий `StiveMan1/Alageum_Temp`, исходный коммит
`10de31ef9344ad00ddf53bf72ec134e56e1322d8`. Исходная дизайн-система `Design/` сохранена.

## Запуск без backend

Нужны Node.js 22+ и npm. Из корня проекта:

```bash
cd frontend
npm ci
npm run dev
```

Открыть http://localhost:3000/catalog

- Каталог: `/catalog`
- Пример карточки: `/catalog/demo-002`
- Сравнение: `/catalog/compare?ids=demo-002,demo-004`
- Локальная подборка: `/selection`

Позиции, параметры и категории демонстрационные. Цены, остатки и документы не
придуманы. Образец не оформляет заказ и не отправляет запрос. Подборка хранится
только в браузере; при недоступном хранилище работает до закрытия страницы.

## Проверки

```bash
npm run lint
npm run test:unit
npm run build
npm run test:e2e:catalog
```

Для Playwright предварительно установить Chromium (`npx playwright install chromium`),
либо указать путь к уже установленному браузеру через `CHROMIUM_PATH`.
Точное покрытие и ограничения: `docs/catalog-verification.md`.
